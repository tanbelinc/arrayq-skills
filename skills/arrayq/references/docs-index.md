# ArrayQ docs index

The ArrayQ docs live at [https://arrayq.com/docs](https://arrayq.com/docs).
Pages marked as not written yet only hold a placeholder today.

## Getting Started

- [ArrayQ Documentation](https://arrayq.com/docs): Guides for running your business on ArrayQ. Learn how to build a booking website, connect it to your account and manage every job from one place.
- [Agent Skills](https://arrayq.com/docs/agent-skills): Install the ArrayQ agent skills so your AI agent knows how ArrayQ works and can build a Site Builder website that is ready to upload and publish.

## Site Builder

- [Site Builder Overview](https://arrayq.com/docs/site-builder): How ArrayQ Site Builder works. Build a Liquid theme, publish it on ArrayQ and get server-rendered pages filled with your services, plus a built-in checkout, sign in and customer account.
- [Build Your Site with AI](https://arrayq.com/docs/site-builder/build-with-ai): A complete, copyable prompt that lets ChatGPT, Claude or any AI coding tool build a ready-to-publish ArrayQ Site Builder Liquid theme in one go, rendered on the server with your services and wired to the built-in checkout, sign in and customer account pages.
- [Build Your Site](https://arrayq.com/docs/site-builder/build-your-site): The folder structure, routing, layout, snippets and link rules for a Liquid theme on ArrayQ Site Builder. Pages are rendered on the server with your services, so they are fully indexable by search engines.
- [Theme Data](https://arrayq.com/docs/site-builder/theme-data): Every object and field you can use in an ArrayQ Site Builder Liquid theme, including your business profile, services, categories and items, plus filters, escaping and caching.
- [Built-in Pages](https://arrayq.com/docs/site-builder/built-in-pages): Every site hosted on ArrayQ gets a ready-made checkout, sign in, registration and customer account with order tracking and live chat. Link to them from your pages instead of building your own.
- [Connect Your Site](https://arrayq.com/docs/site-builder/api-key): Liquid themes on ArrayQ need no API key. When your own browser scripts call the ArrayQ API, load the config.js file ArrayQ serves. Use the site key only for websites hosted elsewhere.
- [Services and Booking API](https://arrayq.com/docs/site-builder/services-and-booking): The public ArrayQ API for loading services and creating bookings from JavaScript. Use it for custom checkout pages, plain HTML sites and websites hosted outside ArrayQ. Liquid themes get services without it.
- [Build a Custom Checkout Page](https://arrayq.com/docs/site-builder/checkout-page): An optional, fully custom booking checkout page for ArrayQ Site Builder. Most sites should link to the built-in checkout instead. Use this when you need your own booking form or host your site elsewhere.
- [Publish Your Site](https://arrayq.com/docs/site-builder/publish): Upload your theme folder to ArrayQ Site Builder, preview it on desktop, tablet and mobile, publish updates and remove a site you no longer need.
- [Visitor Tracker](https://arrayq.com/docs/site-builder/tracker): Track page views, clicks and form submissions on your website with the ArrayQ tracker, on sites hosted by ArrayQ or anywhere else.
- [Orca Chatbot](https://arrayq.com/docs/site-builder/orca-chatbot): Add the Orca AI chat assistant to your website so visitors can ask questions and book services any time, on ArrayQ hosted sites or elsewhere.
- [Connect a Custom Domain](https://arrayq.com/docs/site-builder/custom-domain): Serve your ArrayQ Site Builder website on your own domain. Add a CNAME record, verify it and get HTTPS set up automatically.
- [Troubleshooting](https://arrayq.com/docs/site-builder/troubleshooting): Fix common ArrayQ Site Builder problems, from Liquid errors and missing services to upload failures, broken links and custom domain issues.
